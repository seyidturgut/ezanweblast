# Ezan Vakti Pro Web 2026

Ezan Vakti Pro mobil uygulamasının modern, hızlı ve çok dilli (TR, EN, AR, DE, FR) web tanıtım sayfası.

## 🚀 Özellikler

*   **Modern Teknoloji:** Angular v19+, Standalone Components, Zoneless Architecture.
*   **Tasarım:** Tailwind CSS ile geliştirilmiş, tamamen responsive ve Dark Mode destekli arayüz.
*   **Çoklu Dil Desteği:** 5 farklı dil desteği (Türkçe, İngilizce, Arapça, Almanca, Fransızca).
*   **Namaz Vakitleri:** GPS veya Şehir bazlı otomatik namaz vakti hesaplama.
*   **Canlı Radyo:** Metadata destekli, görsel efektli Online Kuran Radyosu.
*   **SEO:** Google standartlarına tam uyumlu Meta etiketleri, JSON-LD Schema ve Sitemap.

## 🛠 Kurulum

Projeyi yerel ortamınızda çalıştırmak için:

1.  Repoyu klonlayın veya indirin.
2.  Bağımlılıkları yükleyin:
    ```bash
    npm install
    ```
3.  Uygulamayı başlatın:
    ```bash
    npm start
    ```
4.  Tarayıcıda açın: `http://localhost:4200`

## 📂 Proje Yapısı

*   `src/components`: UI bileşenleri (Hero, Features, Radyo vb.)
*   `src/services`: Veri servisleri (Translation, PrayerTimes, SEO vb.)
*   `public`: Statik dosyalar (Görseller, robots.txt, sitemap.xml)
